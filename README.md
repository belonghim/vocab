# 단어 연습장

타이핑으로 정답을 입력하는 단어 암기 웹앱. 서버 없이 정적 파일만으로 동작합니다.

## GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만듭니다 (예: `vocab`). **Public**으로 만드는 게 가장 간단합니다.
2. `index.html`, `words.json`, `README.md`를 저장소 최상단에 업로드하고 커밋합니다.
   - 웹에서 하려면: 저장소 화면 → **Add file** → **Upload files** → 파일 끌어다 놓기 → **Commit changes**
3. 저장소 **Settings** → 왼쪽 메뉴 **Pages** → Source를 `Deploy from a branch`,
   Branch를 `main` / `/ (root)`로 지정하고 **Save**.
4. 1~2분 뒤 `https://<아이디>.github.io/vocab/` 으로 접속됩니다.

폰에서 열어 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

## 단어 넣는 방법 두 가지

**1) 앱에서 붙여넣기** — `단어장` 화면의 입력칸에 한 줄에 하나씩 붙여넣습니다.
쉼표, 탭, `|`, `=` 중 무엇으로 나눠도 읽습니다. 엑셀이나 구글 시트에서 두 칸을
복사해 붙여넣으면 탭으로 구분되어 그대로 들어갑니다.

```
apple, 사과
abandon, 버리다 / 포기하다
```

붙여넣은 단어는 브라우저(localStorage)에 저장됩니다. 이 저장은 **브라우저마다 따로**라
PC와 폰이 서로 공유되지 않습니다.

**2) `words.json` 파일 수정** — 저장소의 파일을 직접 고치면 어느 기기에서 열어도
같은 단어가 나옵니다.

```json
[
  { "f": "apple", "b": "사과" },
  { "f": "abandon", "b": "버리다 / 포기하다" }
]
```

`f`는 단어, `b`는 뜻입니다. `["apple", "사과"]` 같은 배열 형태나
`{"word": "...", "meaning": "..."}` 형태도 읽습니다.

두 방법을 섞어 쓰는 흐름은 이렇습니다. 평소엔 앱에서 편하게 붙여넣어 쓰다가,
`단어장` 화면의 **words.json 내려받기**를 눌러 받은 파일을 저장소의 `words.json`에
덮어쓰고 커밋하면 다른 기기와 맞춰집니다.

## 채점 규칙

- 대소문자와 앞뒤 공백은 무시합니다.
- 뜻이 `/` 또는 `;`로 나뉘어 있으면 그중 하나만 맞아도 정답입니다.
- 괄호 안 설명은 없어도 정답으로 봅니다. `사과(과일)` → `사과`도 정답.
- 한글 답은 띄어쓰기가 달라도 정답으로 봅니다.

## 문제 순서

맞은 횟수와 틀린 횟수를 단어별로 기록해서, 자주 틀린 단어와 아직 안 풀어본 단어를
먼저 냅니다. 이 기록도 브라우저에 저장되며 `words.json`에는 포함되지 않습니다.
